# Portfolio — Nariswari Nur Shabrina

Interactive personal portfolio: AI · Machine Learning · NLP · UI/UX.

**Live:** https://nariswarins.github.io/Portofolio_Naris/

## Editing content

All content (experience, projects, skills, certifications) lives in [`assets/js/data.js`](assets/js/data.js).
Edit that file, commit, and push — GitHub Pages updates automatically.

## Run locally

Open `index.html` in a browser, or run `python -m http.server` in this folder and visit http://localhost:8000.
